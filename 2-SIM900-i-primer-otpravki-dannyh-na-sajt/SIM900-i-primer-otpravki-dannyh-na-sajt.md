#### [2. Комплексная библиотека Arduino SIM900 Shield](https://github.com/nthnn/SIM900)

В каталоге ***SIM900-2025-08-01*** находится загруженный архив репозитария ***SIM900-main***, который может быть установлен в ардуино:

Installation - to use this library, follow these steps:

1. Download the library from the GitHub [repository](https://github.com/nthnn/SIM900).
2. Open your Arduino IDE.
3. Click on `Sketch` -> `Include Library` -> `Add .ZIP Library...`
4. Select the downloaded library ZIP file.
